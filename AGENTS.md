# Prosjektteam for Angelsen Byggservice

Hovedassistenten er Eriks kontaktpunkt og har ansvar for helhet, koordinering og sluttresultat. Følg Eriks personlige instruksjoner og arbeidsorkestratoren. Bruk relevante prosjektagenter i `.codex/agents/` når oppgaven og tilgjengelige verktøy gjør delegering nyttig og tillatt. Velg bare rollene som trengs; små oppgaver krever ikke et helt team. Ved parallelle oppgaver skal hver agent ha et tydelig mandat og avgrensede filer eller være skrivebeskyttet etter instruks. Hovedassistenten samordner og kontrollerer resultatene.

Teamet dekker produktledelse, UX, visuell design, frontend, backend/arkitektur, sikkerhet/personvern, kvalitet/tilgjengelighet, innhold/SEO og DevOps/release. Agentene er prosjektkonfigurasjon og starter bare når de tas i bruk; de er ikke selvstendige tjenester eller garanti for at alle verktøy er tilgjengelige.

Nettsiden er i dag statisk HTML, CSS og JavaScript. Les eksisterende filer før endringer, bevar arbeid som finnes, og kontroller relevante brukerreiser. README beskriver admin som innlogging på klientsiden og lagring i nettleseren; undersøk faktisk kode før konklusjoner, og behandle ikke dette som reell tilgangskontroll eller publisering. Unngå å legge hemmeligheter i klientkode, dokumentasjon eller agentrapporter.

For utgivelser: kartlegg faktisk hosting og publiseringsløp, kontroller endringer, relevante tester, tilgjengelighet og sikkerhet i forhold til risiko, og vurder verifisering etter publisering og mulighet for tilbakeføring. Meld tydelig fra om kontroller som ikke er utført. Ikke hev at noe er publisert eller testet uten dokumentasjon. Følg Eriks anvisninger om publisering og gjeldende tillatelser.
